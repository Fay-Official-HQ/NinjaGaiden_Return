# 新角色素材与音效配置指南

> 适用于：多角色共用一套玩家代码（Ryu 旧角色 / ChangFei 新角色），但需要各自独立的必杀技/处决特效贴图和音效。
> 更新日期：2026-08-19

---

## 一、这次改了什么（背景）

原来的玩家脚本里，必杀技（真龍閃華）和处决（灭杀连斩）的**残影贴图**、以及所有**音效 ID** 都是硬编码在代码里的：

- `DragonFlashState.gd` / `ExterminateChainState.gd` 里写死了 `res://assets/sprites/Ryu/shadows/shadow_pose_*.png`
- 所有状态脚本里写死了 `AudioManager.play_sound(&"cuoa")` 之类的音效 ID

两个角色共用同一套脚本 → 新角色只能用旧角色的素材。

### 解决方案：每角色一份「素材配置资源」

新增一个可配置的资源类 `CharacterAssets`，把"角色专属的东西"全部从代码里抽出来。**代码共用，数据分家**：

| 配置项 | 类型 | 用途 |
|---|---|---|
| `shadow_textures` | Array | 必杀技/处决共用的 5 张残影贴图 |
| `final_phantom_texture` | Texture2D | 必杀技最后一击的大刀幻影贴图 |
| `sound_overrides` | Dictionary | 音效覆盖表：`"默认音效ID": "该角色专属音效ID"` |

- 旧角色（Ryu）的 `assets` 属性**不设置** → 自动回退到脚本里的 Ryu 默认值，**零改动、行为不变**
- 新角色（CF）在场景根节点挂上自己的 `CharacterAssets_CF.tres` 即可

### 改动文件清单

| 文件 | 操作 | 说明 |
|---|---|---|
| `resources/player/CharacterAssets.gd` | 新增 | 配置资源类（默认值 = Ryu 素材） |
| `resources/player/CharacterAssets_CF.tres` | 新增 | CF 的配置：残影 = ChangFei66~70 |
| `scripts/player/Player.gd` | 修改 | 新增 `@export assets`、`get_assets()`、`get_shadow_textures()`、`get_final_phantom_texture()`、音效统一出口 `play_sound()` / `play_sfx_fade_in()` |
| `scripts/player/states/DragonFlashState.gd` | 修改 | 残影/大刀幻影改从配置读取；音效走 `player.play_sound()` |
| `scripts/player/states/ExterminateChainState.gd` | 修改 | 残影改从配置读取；`cuoa` 走 `player.play_sound()` |
| `scripts/player/states/ExterminateReleaseState.gd` | 修改 | `bishaji`/`jianxiapi` 走 `player.play_sound()` |
| 其余 9 个状态脚本（Jump/Hang/Fall/Hurt/Wall/SwordUppercut/SwordDownslash/SwordDash/SwordSpin） | 修改 | 音效统一走 `player.play_sound()` |
| `scenes/player/CF.tscn` | 修改 | 根节点挂上 `assets = CharacterAssets_CF.tres` |

> `player.tscn`（Ryu）完全没动。

## 二、以后怎么给新角色换音效（核心教程）

音效系统是「事件 ID」制：代码里用 `&"cuoa"` 这类 ID 播声音，ID 通过 `.tres`（`SoundEventResource`）注册到全局 `SoundRegistry`。

给 CF 换专属音效只需 **4 步，全程不改代码**：

### 第 1 步：准备音效文件
把新音效（.wav / .ogg）放进 `assets/audio/player/`（或其它音频目录）。

### 第 2 步：建 SoundEventResource 配置
在 `resources/audio/player/` 下新建 `.tres`，参考现有的 `cuoa.tres`：

```ini
[gd_resource type="Resource" script_class="SoundEventResource" format=3]

[ext_resource type="Script" path="res://resources/audio/SoundEventResource.gd" id="1_sound"]
[ext_resource type="AudioStream" path="res://assets/audio/player/你的新音效.wav" id="2_sound"]

[resource]
script = ExtResource("1_sound")
event_id = &"cf_cuoa"        ; ← 新 ID，建议加角色前缀
stream = ExtResource("2_sound")
volume_db = -15.0
```

> 复制粘贴现有的 `resources/audio/player/cuoa.tres` 改更快。

### 第 3 步：注册到 SoundRegistry
打开 `autoload/SoundRegistry.gd`，在 `_audio_files` 数组里加一行新路径：
```gdscript
"res://resources/audio/player/cf_cuoa.tres",
```

### 第 4 步：在角色配置里加覆盖条目
打开该角色的 `CharacterAssets_XXX.tres`（CF 的就是 `CharacterAssets_CF.tres`），在检查器中编辑 `sound_overrides`，加一条：

| key（默认音效 ID） | value（该角色专属 ID） |
|---|---|
| `cuoa` | `cf_cuoa` |

> 也可以在文本里直接加：`sound_overrides = {"cuoa": "cf_cuoa"}`

重要：在这里要注意，需要在编辑器中操作资源，1.直接在下方空格填写String类型2.然后点击增加按钮即可

完成。游戏运行后，CF 播 `cuoa` 时自动改播 `cf_cuoa`；Ryu 不受影响。

## 三、怎么给新角色换必杀技/处决贴图

打开该角色的 `CharacterAssets_XXX.tres`，在检查器中替换：

1. **`shadow_textures`**：5 张残影贴图，对应必杀技波次残影 + 处决连斩残影
2. **`final_phantom_texture`**：必杀技最后一击的大刀幻影图
   - ⚠️ CF 目前**未设置**这一项 → 暂时沿用 Ryu 的 `dadao_004.png`，等有了张飞版大刀图，在这里替换即可

## 四、新加一个角色（完整流程）

1. 建角色动画场景（参考 CF.tscn，根节点脚本用 Player.gd）
2. 把新角色的残影图放进 `assets/sprites/XXX/shadows/`
3. 复制 `CharacterAssets_CF.tres` 改名 `CharacterAssets_XXX.tres`，替换贴图路径
4. 场景根节点 `assets` 属性挂上该 tres
5. 音效按第二节流程走（建 tres → 注册 → 加覆盖条目）
6. 测试用 `scenes/levels/testLevel/testLevel.tscn`（唯一用 CF 的关卡）；正式关卡用旧角色

## 五、踩过的坑（重要）

1. **`.tres` 里别用类型化数组语法**：
   ❌ `shadow_textures = Array[ExtResource("2"), ...]` → 解析报错 `Expected ']'`，整个资源加载失败
   ✅ `shadow_textures = [ExtResource("2"), ExtResource("3"), ...]`（普通数组）
2. **改完脚本要重启编辑器**：Godot 热重载可能不重新初始化已存在的实例，出现"改了没生效"时要重启。
3. **别跑错关卡**：正式关卡（Level_1 等）和 F5 进游戏都是旧角色 Ryu，用旧图是**正常**的；测 CF 一定要 F6 运行 `testLevel.tscn`。
